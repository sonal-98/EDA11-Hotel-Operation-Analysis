# Hotel Operations Analysis

## Project Overview

An Exploratory Data Analysis project designed to analyze hotel booking operations, guest behavior, cancellation patterns, and revenue-related metrics for improving hospitality operations.

## Business Context

The project focuses on identifying booking and customer patterns that can help hotel management improve operational efficiency, guest satisfaction, loyalty and revenue management.

## Objectives
Analyze booking trends and hotel types.
Identify important booking channels and market segments.
Study cancellation behavior.
Analyze guest preferences and repeat guests.
Examine lead time and stay duration.
Analyze ADR and revenue-related indicators.
Generate actionable operational insights.

## Analysis Performed
Data cleaning and preprocessing.
Missing-value treatment.
Date conversion.
Duplicate and inconsistent-value analysis.
Booking and market-segment analysis.
Guest behavior analysis.
Cancellation analysis.
Revenue and ADR analysis.
Visualizations

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Hospitality Analytics, Business Analysis, Data Cleaning, Statistical Analysis, and Data Visualization.
